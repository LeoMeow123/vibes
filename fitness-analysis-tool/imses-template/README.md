# IMSES Portfolio Website Template

A ready-to-use portfolio website template for the **Intelligent Multi-Sensor Elbow Sleeve** research project. Designed to showcase the project to university admissions officers.

**[Live example (Jiayang Bai's version)](https://jiayangb.github.io/imses/)**

## What's Included

- `index.html` — Main portfolio website with 8 tabbed sections
- `demo.html` — Interactive app demo with device scanning, live sensors, daily/weekly summaries, and feedback
- `assets/` — Project logo, structure diagrams, Ready Player One inspiration image

## How to Use

### 1. Fork or copy this folder

### 2. Customize — search for `[Your Name]` and replace with your info:
- `[Your Name]` — your full name (appears in sidebar, about, footer)
- `[Your School]` — your high school name
- `[username]` — your GitHub username
- `your-email@example.com` — your contact email
- `[Y]` — your initial (in the avatar circle)

### 3. Add your photo
- Add `assets/your-photo.jpg` (recommended: 600×724px)
- Uncomment the `<img>` tag in the About Me section

### 4. Customize content
- **Overview & Prototype** — add real prototype photos
- **Engineering Design** — update sensor specs if different
- **Motivation & Novelty** — adjust the inspiration story
- **The Science** — update formulas for your specific sensors
- **About Me** — rewrite the personal paragraphs, research, activities
- **Contact** — add your real email and GitHub

### 5. Deploy
- Push to GitHub → enable GitHub Pages → your site is live
- Or drag the folder onto [Netlify Drop](https://app.netlify.com/drop)
