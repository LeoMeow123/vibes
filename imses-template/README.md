# IMSES — Portfolio Website Template

A ready-to-use portfolio website for the **Intelligent Multi-Sensor Elbow Sleeve** research project. Designed to showcase the project to university admissions officers.

**[Live example (Jiayang Bai's version)](https://jiayangb.github.io/imses/)** · **[Live template](https://leomeow123.github.io/vibes/imses-template/)**

## What's Included

| File | Description |
|------|-------------|
| `index.html` | Main portfolio website — 8 tabbed sections with sidebar navigation |
| `demo.html` | Interactive app demo — device scanning, live sensors, daily/weekly summaries, feedback |
| `assets/` | Project logo, structure diagrams, inspiration image |

## Quick Start

1. **Copy** this folder into your own GitHub repo
2. **Search** for `[Your Name]` and replace with your info
3. **Add** your photo to `assets/your-photo.jpg`
4. **Enable** GitHub Pages → your site is live

## What to Customize

| Placeholder | Replace with |
|-------------|-------------|
| `[Your Name]` | Your full name |
| `[Your School]` | Your high school |
| `[username]` | Your GitHub username |
| `your-email@example.com` | Your contact email |
| `[Y]` | Your initial (avatar circle) |

| # | Section | Content |

## Demo App

The demo (`demo.html`) is a standalone interactive app with:

- **Landing screen** — IMSES logo, "Search for nearby devices" with scanning animation, Developer Mode
- **Live tab** — Real-time sensor gauges cycling through 8 behaviors
- **Daily tab** — Pie chart, sensor averages, training metrics
- **Weekly tab** — 7-day bar chart, week-over-week trends
- **Feedback tab** — Personalized tips, session score

## Deployment

**GitHub Pages** (recommended):
```
Push to GitHub → Settings → Pages → Deploy from main branch
```

**Netlify** (alternative):
```
Drag the folder onto https://app.netlify.com/drop
```
